    저장 상태

    앱 목록은 허브의 공유 저장소와 이 기기에 함께 저장됩니다. 백업 파일을 휴대폰 'MY' 폴더에 받아 두면 더 안전합니다.

    기본 규칙

    모든 미니앱이 따르는 디자인과 데이터 원칙 · v1

    데이터 보존 5원칙

    1. 앱을 고칠 때는 항상 같은 주소에 덮어씁니다. 주소가 바뀌면 저장소가 새로 생깁니다.
    2. 항목의 고유번호는 한 번 정하면 바꾸지 않습니다.
    3. 저장 형식이 바뀌면 옛 데이터를 새 형식으로 옮기는 코드를 넣고, 지우지 않습니다.
    4. 공유 저장소와 기기에 이중 저장하고, 앱마다 백업 파일 저장·복원을 둡니다.
    5. 수정할 때마다 현재 데이터 확인 → 수정 → 데이터 그대로인지 재확인합니다.

    새 미니앱 만드는 순서

    1. Claude에게 "MY 미니앱으로 ○○ 만들어줘"라고 요청합니다.
    2. 완성되면 이 허브 '관리'에 이름·주소를 등록합니다. Claude가 등록할 수도 있습니다.
    3. 각 앱의 '백업 파일 저장'으로 휴대폰 MY 폴더에 데이터를 보관합니다.
